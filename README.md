# SkillLens

### AI-Powered Resume Analysis & Career Skill Discovery

SkillLens is an AI-powered career and skill discovery platform that analyzes a user's resume to identify their technical strengths, skill gaps, role compatibility, and potential career paths.

The platform combines **NLP, machine learning, and a modern web interface** to transform unstructured resume information into actionable career insights.

## Live Demo

**[Open SkillLens](https://skillensfrontend.sahinidutta227.workers.dev/)**

## Features

* **Resume Analysis** — Upload a PDF or DOCX resume for automated analysis.
* **Skill Detection** — Extracts relevant technical skills from resume content.
* **Role Prediction** — Predicts the most suitable career role based on the candidate's profile.
* **Match Score** — Calculates compatibility between the resume and predicted career roles.
* **Skill Gap Analysis** — Identifies relevant skills that are currently missing.
* **Career Path Insights** — Presents potential career directions based on the analyzed profile.
* **Similarity Analysis** — Provides role-wise similarity scores generated by the ML pipeline.
* **Responsive Interface** — Designed for desktop and mobile viewing.

## Machine Learning Pipeline

The ML pipeline processes resume text through several stages:

```text
Resume
   │
   ▼
Text Extraction
   │
   ▼
Text Preprocessing
   │
   ▼
TF-IDF Feature Extraction
   │
   ├───────────────► Role Classification
   │
   ├───────────────► Role Similarity Analysis
   │
   └───────────────► Skill Extraction
                         │
                         ▼
                   Skill Gap Analysis
                         │
                         ▼
                 Career Recommendations
```

The trained model artifacts are stored in the `models/` directory and loaded by the backend during analysis.

## Local Development

### 1. Clone the repository

```bash
git clone https://github.com/sahinidutta07/skilllensresume.git
cd skilllensresume
```

### 2. Backend setup

Create and activate a Python virtual environment:

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r backend/requirements.txt
```

Start the Flask server:

```bash
python backend/app.py
```

The API will run at:

```text
http://127.0.0.1:5000
```

### 3. Frontend setup

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

The development server will provide a local URL in the terminal.

## Key Design Goals

SkillLens was designed around four core principles:

1. **Actionable** — Go beyond simply parsing a resume by identifying practical skill gaps.
2. **ML-driven** — Use trained machine-learning components for role prediction and similarity analysis.
3. **Accessible** — Provide a simple workflow for students and job seekers.
4. **Scalable Architecture** — Separate the frontend, API, and ML pipeline for easier maintenance and deployment.
